# Bubble Consult responsive website

A responsive one-page Bubble Consult website built with HTML5, CSS3, Bootstrap 5.3, Bootstrap Icons, and vanilla JavaScript. It follows the supplied wireframe and uses the provided image assets.

## Run locally
1. Extract the project folder if it came as a ZIP.
2. Open `index.html` in a browser. For best results, use VS Code with the Live Server extension.
3. Internet access is required for the Bootstrap CSS/JS and Bootstrap Icons CDN links.

## Features
- Responsive navigation and dropdown
- Hero, brand strip, about, services, contact, team, testimonials, blog, and footer sections
- Testimonial carousel with manual controls and automatic rotation every 5 seconds
- Client-side contact and newsletter form validation and confirmation messages
- Back-to-top button and mobile navigation auto-close

## Important
The contact and newsletter forms are front-end demonstrations only. To receive real submissions, connect them to a backend or a form/email service. Replace placeholder copy, social links, and sample team/testimonial content before publishing.
